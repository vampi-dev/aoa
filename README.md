# Numepy - 40 Beginner-Friendly Algorithm Programs

This folder contains 40 standalone Python files. Each file can be run independently.

## Run a program
Open Command Prompt in this folder and run, for example:

```cmd
python 01_merge_sort.py
```

Change the sample input near the bottom of a file to try your own values.

## Notes
- `08_strassen_matrix_2d.py` is Strassen multiplication for square matrices whose size is a power of two.
- `09_strassen_matrix_3d_batch.py` multiplies corresponding 2D matrices in batches. It is not general 3D tensor Strassen multiplication.
- `12_las_vegas_randomized_quickselect.py` is a randomized Quickselect example.
- `35_optimal_bst.py` assumes successful-search frequencies only.
- `38_set_covering_greedy.py` and `40_vertex_cover_greedy.py` are greedy approximation algorithms.
- `07_radix_sort.py` accepts non-negative integers.
